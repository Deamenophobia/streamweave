# Streamweave v0.2.0 — first public preview

Streamweave is a local-first visual numerical workbench for combining timestamped datasets, connecting reusable calculations, and exploring reproducible outputs. This is an early public preview under the MIT license.

## Included

- A canvas with repeated modules, branching, typed connections, parameter controls, and undo/redo.
- Separate Canvas, Datasets, and Results views; Classic and Studio appearances.
- CSV, JSON, and JSONL imports with explicit timestamps, units, missing values, and availability times.
- Fifteen built-in modules, including timestamp alignment, rolling statistics, correlation, descriptive linear regression, transformations, and chart/table/export outputs.
- Browser execution by default and an optional local Python engine using NumPy/SciPy.
- Reusable Python dataset sessions, changed-result transfer, bounded caches, cooperative cancellation, and periodic cleanup.
- Portable project JSON plus CSV/results JSON exports with engine provenance.
- Versioned documentation, contribution guidance, and checks for both engines.

## Get started

Follow the [README quick start](../../README.md#quick-start). Python is optional; see the [engine guide](../wiki/local-engine.md) for setup and switching. The included two-source study uses synthetic sensor data and requires no account or external data feed.

## Compatibility and limits

Portable project files use version 2. The Python service uses HTTP protocol 2; update the workbench and service together. Earlier HTTP protocol 1 clients are incompatible with this service. Legacy v1 APIs remain available in the core, but the canvas opens v2 projects.

This release is bounded to 12 datasets, 50,000 total input rows, 20,000 rows per dataset, 50 modules, and 120 connections. It has no live connectors, arbitrary script execution, Excel workbook import/export, collaboration, or MATLAB-compatible language. Browser save is explicit; download project JSON to retain a portable copy.

Both engines use binary64 arithmetic. Correlation and regression are descriptive, and performance depends on workload and transfer costs. The [validation record](../validation.md) includes numerical checks, manual browser acceptance, benchmark conditions, and known gaps. There is no claim of universal numerical correctness, forecasting accuracy, or audited production readiness.

Report ordinary problems in [Issues](https://github.com/Deamenophobia/streamweave/issues); use the [security policy](../../SECURITY.md) for vulnerabilities. GitHub is the public code, issue, and release destination. Maintainers also retain a GitLab copy; contributors do not need GitLab access.
